# Electronic_Scram 串口与数据包说明

## 当前链路

Send 和 Receive 使用的 LoRa 串口不同：

```text
Send：    PA0～PA3 按键 -> USART1_TX / PA9 -> LoRa 模块
Receive：LoRa 模块 -> USART3_RX / PB11 -> DMA -> USART1_TX / PA9 -> Master UART7_RX
```

Send 端 USART1（PA9/PA10）连接 LoRa 模块，Receive 端 USART3（PB10/PB11）连接 LoRa 模块。Receive 端 USART1（PA9/PA10）连接 Master 的 UART7；如需反向发送，连接 Master UART7_TX -> Receive PA10。各串口均为 115200、8N1、无硬件流控，TX/RX 交叉连接并共地。

Send 端按键状态帧为 3 字节：

```text
A5 5A status
```

`status` 的低 4 位分别对应 PA0、PA1、PA2、PA3。按键状态变化时立即发送；状态不变时每 100 ms 最多重复发送一次。Send 使用 USART1 DMA 发送，当前不解析 LoRa 回传数据。

Receive 端是透明串口桥：LoRa USART3 收到的字节原样转发到 USART1；USART1 收到的字节原样转发到 USART3，不添加帧头、不修改载荷，也不按 DMA 分段解释报文。

LoRa 模式脚 M0、M1 均由 GPIO 初始化为低电平，进入透明传输模式。

## DMA 配置

| 工程/串口 | 引脚 | 接收 DMA | 发送 DMA |
| --- | --- | --- | --- |
| Send USART1 | TX=PA9、RX=PA10 | DMA1 Channel5，CIRCULAR | DMA1 Channel4，NORMAL |
| Receive USART1 | TX=PA9、RX=PA10 | DMA1 Channel5，CIRCULAR | DMA1 Channel4，NORMAL |
| Receive USART3 | TX=PB10、RX=PB11 | DMA1 Channel3，CIRCULAR | DMA1 Channel2，NORMAL |

Receive 端使用 DMA 循环接收和空闲检测；发送 DMA 使用 NORMAL 模式，避免重复发送旧数据。缓冲区溢出、串口错误和 DMA 重启状态可在调试器中观察。

## 验证步骤

1. 先断开执行机构，只进行串口和 GPIO 测试。
2. 给 Send 的 PA0～PA3 输入按键电平，使用逻辑分析仪观察 PA9 是否发送 `A5 5A status`。
3. 将 Send 与 Receive 的 LoRa 模块配置为空中参数一致，确认 Receive 的 USART1/PA9 能收到对应数据。
4. 用串口工具连接 Receive USART1，检查收到的数据是否与 Send 发送内容一致。
5. 如需验证反向链路，从 Receive USART1 输入字节，检查 LoRa 模块 USART3 是否原样发送。

软件构建通过不等于无线链路已实测连通；最终仍需烧录两端固件并进行实际 LoRa、TX/RX 和共地测试。
