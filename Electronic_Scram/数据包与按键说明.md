# Electronic_Scram 串口与数据包说明

Send 和 Receive 通过各自的 LoRa 模块通信。

```text
Send：    PA0～PA3 按键 -> USART1_TX / PA9 -> LoRa 模块
Receive：LoRa 模块 -> USART3_RX / PB11 -> DMA -> GPIO 输出
```

Send 端 USART1（PA9/PA10）连接 LoRa 模块。Receive 端仅使用 USART3（PB10/PB11）连接 LoRa 模块，不再连接 Master，也不再使用 Receive USART1。串口参数为 115200、8N1、无硬件流控。

Send 发送 3 字节状态帧：

```text
A5 5A status
```

`status` 的低 4 位对应 PA0、PA1、PA2、PA3。Receive 校验帧头后将状态位映射到本板 GPIO。

Receive 使用 USART3 DMA 循环接收。DMA 缓冲区中的数据只在 Receive 本地解析，不转发到 Master。
