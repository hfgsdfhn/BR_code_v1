# Hand_Shank 遥控数据帧说明

遥控器通过 UART6 将数据发送到 `E34-2G4H27D` LoRa 模块（或原有 WiFi 链路）；H723 通过 UART9 接收模块输出的数据并解析。

## 无线模块配置

- LoRa 型号：`E34-2G4H27D`；对端使用匹配的模块和无线参数。
- 正常透传模式：`M0=0`、`M1=0`。当前工程没有映射 M0/M1 控制引脚，需在硬件上将两脚接低，不能悬空。
- 固件不写入模块寄存器；需预先使用外部工具设置 UART 为 **115200、8N1**，选择透传，关闭接收数据附加 RSSI，确保信道、网络地址、空中速率、密钥等参数与对端匹配。
- 当前每 20 ms 发送 8 字节（有效载荷 400 字节/秒）；空中速率需留出协议开销余量，不能直接沿用低速默认配置。

## 通信参数

- 波特率：115200
- 数据位：8
- 停止位：1
- 校验：无
- 帧周期：20 ms
- 帧长度：8 字节

## 数据帧格式

```text
A5 5A BYTE2 BYTE3 BYTE4 BYTE5 BYTE6 BYTE7
```

| 字节偏移 | 字段 | 说明 |
|---:|---|---|
| 0 | `A5` | 帧头第 1 字节 |
| 1 | `5A` | 帧头第 2 字节 |
| 2 | `BYTE2` | 摇杆数据：低 4 位为 X，高 4 位为 Y |
| 3 | `BYTE3` | 第 1 组按键 |
| 4 | `BYTE4` | 肩键 |
| 5 | `BYTE5` | 第 2 组按键 |
| 6 | `BYTE6` | 第 3 组按键 |

## 按键与字节对应关系

所有按键均为低电平按下，协议位为 `1`；松开时协议位为 `0`。

### BYTE3：第 1 组（不含肩键）

| 位 | 手柄输入 | 说明 |
|---:|---|---|
| bit0 | PA6 | 按键 |
| bit1 | PA5 | 按键 |
| bit2 | PA4 | 按键 |
| bit3 | PA1 | 按键 |
| bit4 | PA0 | 按键 |
| bit5 | PC3 | 按键 |



### BYTE4：肩键

| 位 | 手柄输入 | 说明 |
|---:|---|---|
| bit0~bit3 | ADC_CHANNEL_7 | ADC 量化值，范围 `0x0~0xF` |
| bit4~bit7 | ADC_CHANNEL_11 | ADC 量化值，范围 `0x0~0xF` |

### BYTE5：第 2 组
### BYTE6：第 3 组

| 位 | 手柄输入 | 说明 |
|---:|---|---|
| bit0 | PA12 | 按键 |
| bit1 | PE6 | 按键 |
| bit2 | PE3 | 按键 |
| bit3 | PE4 | 按键 |
| bit4 | PE5 | 按键 |
| bit5 | PE2 | 按键 |
| bit6 | PE1 | 按键 |
| bit7 | PE0 | 按键 |

### BYTE7：第 4 组

| 位 | 手柄输入 | 说明 |
|---:|---|---|
| bit0 | PD3 | 按键 |
| bit1 | PD4 | 按键 |
| bit2 | PD7 | 按键 |
| bit3 | PD6 | 按键 |
| bit4 | PD5 | 按键 |
| bit5~bit7 | 保留 | 当前发送为 `0` |

H723 接收端使用 UART9 中断逐字节寻找 `A5 5A`，收满 8 字节后更新遥控状态。
