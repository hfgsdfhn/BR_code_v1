# W5500 UDP 状态通信协议

主控默认地址为 192.168.1.100:5000。每个 UDP 数据报承载一帧，共 18 字节。

| 帧内偏移（字节） | 长度 | 内容 |
| ---: | ---: | --- |
| 0 | 2 | 固定帧头 A5 5A |
| 2 | 14 | send_to_ethernet 载荷 |
| 16 | 2 | CRC-16/MODBUS，低字节在前 |

## 载荷

| 载荷内偏移（字节） | 类型 | 字段 |
| ---: | --- | --- |
| 0 | int16 小端 | vx |
| 2 | int16 小端 | vy |
| 4 | int16 小端 | vw |
| 6 | int16 小端 | yaw |
| 8 | int16 小端 | dt35_left |
| 10 | int16 小端 | dt35_front |
| 12 | uint8 | action_task，主控发送 0，接收时保留原值 |
| 13 | uint8 | remote_state，0 离线，1 在线 |

调用方将物理量乘以 1000 并四舍五入，检查结果可用 int16 表示后再填字段。接收方除以 1000 还原数值。可表示的物理量范围为 -32.768 至 32.767。

调用 `W5500_SendStatus(&status, ip, port)` 发送，返回 `osOK` 表示已入队。调用 `W5500_ReceiveStatus(&status, ip, &port)` 取包，成功时同时返回发送方地址。

## CRC

CRC 覆盖前 16 字节。初始值为 0xFFFF，反射多项式为 0xA001，按位右移，最终异或值为 0x0000。ASCII 123456789 的结果为 0x4B37，线上字节为 37 4B。

帧长、帧头或 CRC 校验失败时丢弃数据报。对端需同步切换到 18 字节帧格式。
