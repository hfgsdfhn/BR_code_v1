- `ETH_RXD0`：STM32 U1.33 -> LAN8742A U4.8
- `ETH_RXD1`：STM32 U1.34 -> LAN8742A U4.7
- `ETH_TXEN`：STM32 U1.48 -> LAN8742A U4.16
- `ETH_TXD0`：STM32 U1.51 -> LAN8742A U4.17

- `ETH_MDC`：STM32 U1.16 -> LAN8742A U4.13

- `ETH_REFCLKO`：STM32 U1.24/PA1 <- LAN8742A U4.14
- `ETH_NRST`：STM32 U1.23/PA0 -> LAN8742A U4.15

LAN8742A 相关器件：

- X1：25 MHz 晶振
- C22/C23：20 pF
- R27：12.4 kΩ，连接 LAN8742A RBIAS
- C24：1 uF

RJ45 相关网表连接：

- U4.3 -> R37 510 Ω -> J1.9
- U4.2 -> R38 510 Ω -> J1.12
- J1.8 -> R39/R40
- R39、R40 在网表中标记为 NC
- J1.10/J1.11 接 GND
- J1.1/J1.2 为 TX 差分
- J1.3/J1.6 为 RX 差分

## LAN8742A 时钟模式判断

LAN8742A 数据手册表格含义：

- `nINTSEL = 1`：REF_CLK 输入模式，需要外部有源时钟从 XTAL1/CLKIN 输入。
- `nINTSEL = 0`：适合使用 LAN8742A 自身 25 MHz 晶振并输出 REFCLKO 的模式。

本板网表中 X1 是接到 LAN8742A XI/XO 的 25 MHz 无源晶振，因此理论上应使用 LAN8742A 输出 50 MHz REFCLKO 到 STM32 PA1 的模式。

判断不能靠 LED 亮灭，应该直接测：

- U4.2 在 nRST 低期间的电压；
- U4.14 复位释放后的 50 MHz；
- STM32 PA1 是否收到 50 MHz；
- XI/XO 是否有 25 MHz 晶振振荡。

## 2026-10-31 当前会话结论：50 MHz 已有但 PHY 未建立链路

### 当前状态

- 已确认 LAN8742A 的 U4.14/REFCLKO 已经有约 50 MHz。
- 这说明 X1 25 MHz 晶振、LAN8742A 内部时钟 PLL、nINTSEL=0 的 REF_CLK 输出模式大概率正常。
- 但电脑网卡仍未建立物理链路（可能仍显示 Disconnected），因此最小 PHY 链路测试尚未通过。
- 当前 `main.c` 仍是 PHY-only 复位测试版本；这会影响后续 LwIP/TCP 通信，但不是判断 RJ45 物理 LINK 的必要条件。

### U4.2 strap 的准确含义

- U4.2 是 LAN8742A 的 `LED2/nINT/nPME/nINTSEL` 复用脚。
- 复位期间，LAN8742A 采样 U4.2 的电平作为 nINTSEL 配置：
  - U4.2 = 0：REF_CLK 输出模式，U4.14 输出 50 MHz；
  - U4.2 = 1：REF_CLK 输入模式，U4.14 等待外部 50 MHz。
- 对当前 25 MHz 晶振方案，U4.2 应使用约 10 kΩ 下拉到 GND；复位释放后 U4.2 继续作为 LED2 输出，下拉电阻不会使输出短路。

### 目前应优先排查的物理链路项目

50 MHz 已经存在后，问题重点转到 RJ45/磁性器件模拟前端，但以下项目仍需实测或按原理图确认，不能全部视为已证实故障：

1. LAN8742A TXP/TXN、RXP/RXN 到磁性器件和 RJ45 的差分对是否接反、错脚或断线；
2. 磁性器件中心抽头是否按 LAN8742A 参考电路连接到 ETH_3V3，并确认去耦；
3. RJ45 HR911105A 的 J1.8（屏蔽/内部磁性器件相关脚）是否按 RJ45 数据手册处理；
4. 网表中 R39、R40 标记为 NC，需根据 HR911105A 与磁性器件实际内部连接确认是否应安装；
5. TX/RX 四个 49.9 Ω 匹配电阻 R23/R24/R25/R26 的阻值、位置、焊接和连接；
6. RJ45 侧 75 Ω 终端、中心抽头偏置、C26 1 nF/高压电容及其接地是否符合参考电路；
7. LAN8742A 的 VDDIO、VDD1A、VDD2A、VDDCR、RBIAS 电压和去耦；
8. 网线、RJ45 插座焊接和电脑网卡端口是否正常。
