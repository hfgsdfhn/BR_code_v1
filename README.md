# BR_code_v1

BR的B3和B5分别控制12V开关和5V开关，B7和B8分别控制两个缓启动电机电源开关

#底盘can小板通信协议

小板间的通信都用CAN1
小端序
主控 to 底盘小板
                   CAN ID 0x81：4个int16，发送目标速度
                   CAN ID 0x82：4个int16，发送目标电流
                   数据按小端序排列
主控 to 大疆小板    1，2： 选择行动模式，前一个字节控制四个3508升降，后一个字节控制上台阶的模式
                   3，4，5，6：float32 发送一个目标速度

底盘小板 to 主控    目前只提供通用发送接口，电机状态上报暂不实现
